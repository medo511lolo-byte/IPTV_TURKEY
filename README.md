# 📺 IPTV Turkey Player

مشغّل IPTV كامل مثل IPTV Smarters Player باستخدام Flutter يدعم Android و iOS.

## ✨ المميزات

- 🔐 دعم تسجيل الدخول بواسطة Xtream Codes API
- 📺 عرض قائمة القنوات المباشرة (Live TV)
- ▶️ مشغّل فيديو متقدم باستخدام Better Player
- 📱 يعمل على Android و iOS
- 🎨 واجهة مستخدم بسيطة وجميلة

## 📋 المتطلبات

- Flutter SDK 3.0.0 أو أحدث
- Dart SDK
- Android Studio / Xcode (حسب المنصة)

## 🚀 التثبيت

### 1. تثبيت التبعيات

```bash
flutter pub get
```

### 2. تشغيل المشروع

**Android:**
```bash
flutter run
```

**iOS:**
```bash
cd ios
pod install
cd ..
flutter run
```

## 📱 كيفية الاستخدام

1. **تسجيل الدخول:**
   - أدخل رابط الخادم (Server URL)
   - أدخل اسم المستخدم (Username)
   - أدخل كلمة المرور (Password)
   - اضغط على LOGIN

2. **مشاهدة القنوات:**
   - اضغط على "Live TV" من الصفحة الرئيسية
   - اختر القناة التي تريد مشاهدتها
   - سيتم تشغيل القناة تلقائياً

## 📂 هيكل المشروع

```
lib/
```

## 🔧 التبعيات المستخدمة

- **http**: للاتصال بـ API
- **better_player**: مشغّل فيديو متقدم
- **shared_preferences**: لحفظ بيانات المستخدم

## ⚙️ إعدادات مهمة

### iOS
تم إضافة `NSAppTransportSecurity` في `Info.plist` للسماح بالاتصالات غير المشفرة (HTTP).

### Android
تم إضافة `android:usesCleartextTraffic="true"` في `AndroidManifest.xml` للسماح بالاتصالات غير المشفرة.
